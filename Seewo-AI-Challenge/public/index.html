核心能力

把"批改"做成"诊断"——AI 不仅打勾打叉，还告诉教师为什么错、告诉学生下一步该练什么。

⚙️

模块化 AI 引擎

5 步推理链透明可追溯：OCR → 推理 → 知识图谱 → 诊断 → 策略，决策全程留痕。

🔍

步骤级批改

解答题按步骤给分 + 错因分类，定位卡壳步骤而非只看最终答案。

💬

苏格拉底式辅导

Math Coach 追问不给答案，引导学生自己走出下一步，养成可迁移的思考力。

📷

拍照即批改

手机拍作业本 → OCR → 推理 → 反馈 ≤ 30s，无需手动输入。

📊

置信度排序复核

教师只处理约 15% 低置信度结果，AI 标注的疑点一目了然。

🔁

订正闭环推送

错 1 练 3：变式题 A/B/C 三档分层推送，订正完成率班级看板追踪。

技术栈

开源、零外部闭源依赖；本地 5 分钟跑通；生产可上 Docker / Vercel。

Python 3.11 Flask PaddleOCR DeepSeek-Math (LLM) Gunicorn + Nginx Docker Tailwind + Jinja2 SQLite (demo) → Postgres (prod)

快速开始

三种方式，任选其一。推荐「在线体验」——已部署上云，点开即用，无需任何安装。

方式一 · 在线体验 已上线

Demo 已部署在云服务器（gunicorn + HTTPS 证书），点开即用，无需安装任何环境。教师端 /teacher，学生端 /student，共 13 个页面。

方式二 · Codespaces 一键启动

想在完整开发环境里改代码？GitHub Codespaces 云端拉起环境，自动安装依赖并启动 Demo，浏览器打开 localhost:5000 即可。免费额度足够体验。

一键启动环境 →

克隆仓库、装 Flask、启动，浏览器打开 http://localhost:5000。Windows 用户可双击 demo/start.bat 一键启动。

cd Seewo-AI-Challenge
pip install -r requirements.txt
cd demo && python app.py
